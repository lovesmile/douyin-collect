# 穿戴甲账号非可识别固定模特工作流

这套流程的核心是：人物氛围用文字固定，不上传固定模特参考图；后续模特专注手部和装扮，尽量不露脸；装扮按甲片风格轮换，甲片款式每天以你的真实上手图为准。

因为豆包/Seedance 可能拒绝把固定模特图片当参考图使用，所以固定模特资产要改成“无露脸手部装扮文字卡”：锁定手型、发型发色局部、肩颈比例、穿搭体系、宝蓝色小蝴蝶结、帽子/墨镜/包/首饰和整体气质。日常生成时不上传人物参考图，画面优先只出现手部、袖口、高级衣物质感、肩颈、锁骨、发丝、帽檐、包、首饰或模糊背影，不出现正脸和清晰五官。手部默认按商业手模状态优化：皮肤白皙干净、细腻通透，指节匀净，关节皱纹少。

硬规则：日常图生视频只上传当天真实穿戴甲上手图，不上传固定模特图、四视图、装扮变体图或真人照作为人物参考图。人物部分直接写进提示词。

## 一、生成文字身份卡和内部风格图

运行：

```powershell
cd C:\Users\10385\Projects\wo\douyin-collect
npm run brand:model-prompt -- --out "C:\Users\10385\Projects\wo\outputs\brand-model"
```

会生成：

- `brand-model-four-view-prompt.txt`：非可识别基础身份四视图提示词，兼容旧文件名；只用于内部看风格，不作为参考图上传。
- `brand-model-identity-prompt.txt`：同上，更明确表示这是身份图；只用于内部看风格，不作为参考图上传。
- `brand-model-outfit-variants.md`：6 套非可识别固定模特装扮变体文字库；可直接生成内部风格样张，但不作为参考图上传。
- `brand-model-usage-prompt.md`：每天生成图文或视频时使用的通用规则。
- `seedance-fixed-model-prompt.md`：非可识别固定模特版 Seedance 视频提示词，人物由文字设定生成，只上传甲片图。

生成时注意：

- 尽量不露脸。
- 不要正脸。
- 不要高清五官。
- 不要证件照式人脸。
- 画面重点放在手部、甲片、袖口、高级衣物质感、肩颈、发丝、帽檐、包、首饰和场景氛围。
- 手部要像商业手模状态：皮肤白皙干净、细腻通透，指节匀净，关节皱纹少、干纹少、泛红少，但仍保留真实皮肤纹理和自然骨节。
- 服装、袖口、包和配饰要有真实高质感材质：细腻针织、真丝/缎面、柔软羊毛、干净棉质、轻奢皮革、精致蕾丝、金属链条、珍珠/水晶配饰；布料要有真实纹理、垂坠、光泽和自然褶皱。
- 如果脸部边缘不可避免入镜，必须自然柔焦、浅景深虚化、低清晰度，或被手机、墨镜、发丝、帽檐、裁切、侧脸角度部分遮挡。

## 二、是否需要提前生成装扮变体

可以提前生成 3-6 张装扮变体图给自己看风格，但不要上传给豆包/Seedance 当参考图。真正出片时，只复制对应装扮文字描述，让 AI 直接生成背景人物。

建议至少先做这 4 套：

1. 珍珠蝴蝶结 / 奶白 / 蓝白甜美款
2. 冰透猫眼 / 蓝紫 / 清冷显白款
3. 爆闪钻饰 / 约会仙气款
4. 裸色通勤 / 温柔日常款

如果你的款式里经常有黑银、克罗心、新中式，再补：

5. 黑银甜酷 / 金属款
6. 新中式 / 红金节日款

## 三、每天怎么组合

每天做内容时上传：

1. 当天穿戴甲真实上手图。
2. 如果需要，还可以上传对标样本截图，但只参考构图、机位、节奏、氛围。

不要上传：

- 固定模特图。
- 四视图。
- 装扮变体图。
- 真人照或任何可识别人物参考图。

优先级：

- 人物氛围是谁：以固定文字身份卡为准，不上传人物参考图，不锁清晰人脸；优先不露脸，只锁定手部、装扮、发丝、帽子、配饰和气质。
- 穿什么：以当天甲片风格匹配的装扮文字为准，也可以让 AI 轻微调整，但不要换掉整体气质。
- 甲片是什么样：以当天真实穿戴甲上手图为准。
- 怎么拍：参考每日采集拆解出来的对标样本。
- 图生视频构图：成片仍为 9:16，但顶部 12%-15% 和底部 12%-15% 预留给水印/按钮，只放干净背景、虚化光影或无意义环境；人物、手、手指、甲片和关键道具必须放在中间主体安全区。
- 手部精修：按商业手模状态优化，皮肤白皙干净、细腻通透，指节匀净，关节皱纹少、干纹少、泛红少；可以轻度淡化关节皱纹、指节暗沉、干纹、倒刺、泛红和小瑕疵；但必须保留真实皮肤纹理、自然骨节、手型、甲片边缘和贴合关系，不要磨成塑料手。
- 衣物质感：服装、袖口、包和配饰必须有真实高质感材质和细节，不要廉价塑料感、粗糙脏乱布料或劣质配饰。

## 五、每天提示词里的固定规则

可以在任何图文或视频提示词前加：

```text
人物装扮必须根据当天上传的穿戴甲参考图款式来搭配。
使用上传的穿戴甲参考图作为甲片参考，严格锁定甲型、颜色、渐变、钻饰、珍珠、蝴蝶结和装饰位置。

不要改变甲片款式，不要改变手指数量，不要新增甲片装饰，不要文字、logo、水印、贴纸或 AI 字样。
```

## 六、什么时候需要重新生成模特

不要因为某一天数据差就换模特。至少连续使用 30 天同一个非可识别基础模特氛围。

只有这些情况才考虑重做：

- 基础身份图依然露出清晰人脸，导致 AI 工具拒绝使用。
- 手型明显不稳定，图生视频经常多手或畸形手。
- 账号定位变了，比如从甜美轻奢转成纯甜酷或纯新中式。
- 连续 30 天数据验证后，固定人物氛围记忆点确实不适合账号。
